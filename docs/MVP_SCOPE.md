# MVP scope

Status: Proposed, demo-first. Not a launch specification.

## In scope

- Responsive learner-facing landing/discovery experience, tutor cards and profiles, search and useful filters.
- Matching wizard with deterministic mock ranking and “why this match” explanations.
- Booking request, availability slots, schedule view, and booking state transitions using local demo persistence if approved.
- Demo chat thread with seeded messages and safe empty states.
- Creator resource catalog with notes/course/video lesson samples and simulated purchase confirmation.
- Study assistant mock with concept explanation and quiz prompts; explicit AI demo label.
- Educator dashboard for request review, booking management, availability, profile summary, resource publishing, and demo earnings.
- Saved mentors and locality/rate filters for learners; resource subject filters and detail pages.
- Admin demo view for verification queue and content review.
- Synthetic seed dataset, accessible components, responsive layout, empty/loading/error states.

## Out of scope without explicit approval

- Live payments, payouts, wallet balances, refunds, tax handling, or payment credentials.
- Production deployment, custom domain, public marketing claims, or user acquisition.
- Real student, tutor, minor, identity, location, financial, or educational records.
- Identity/background verification, messaging delivery, maps/geocoding, email/SMS, analytics, or file hosting providers.
- AI provider calls or sending user content to external models.
- Legal/compliance claims or operating policy for a real marketplace.

## Definition of demo-ready

All primary journeys are navigable and have believable synthetic data; controls provide visible feedback; demo-only behavior is labeled; no secret or real personal data is embedded; responsive layouts and keyboard basics are covered; setup and limitations are documented.
